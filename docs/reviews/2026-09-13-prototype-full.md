# 専門家評議会レポート：4ターン体験版

- 実施日：2026-09-13
- モード：`full`
- 対象：現在の4ターン体験版、ゲームデータ、計算、画面
- 方法：6つの専門視点による独立レビュー後、共通点と対立点を統合
- 範囲外：コード修正、史実の外部照合、公開、外部AI API

## 経営判断サマリー

### 維持すべき強み

- 4ターンのテンポが良く、一周しやすい。
- 利点と不利益、遅延効果、政策連鎖という戦略ゲームの骨格がある。
- ゲームデータと計算が分離され、結果も説明しやすい。
- 創作人物と架空新聞を明示し、特定政党へ誘導していない。
- 大きいボタン、キーボード操作、符号付き数値などの基礎的配慮がある。

### 最重要問題

1. 「限られた予算」が全81経路で一度も選択を制約せず、中心テーマと遊びが一致していない。
2. プレイヤーの役職と権限が曖昧で、政策決定と完全実施がボタン一回で同時に起きる。
3. SDGs平均が52〜55に集中し、街は81経路中73経路が同じ状態、曇り状態は0経路になる。
4. 政策結果の多くが数値と共通新聞だけで、誰の暮らしがどう変わったか見えない。
5. 史実、仮想、ゲーム上の仮定をデータとして分類できず、出典項目もない。

### 今回は行わないこと

- 340件の政策データ投入
- ランキングやオンライン機能
- 外部AI APIを使うゲーム内レビュー
- UI演出だけによる問題の覆い隠し

## 意見の一致

- 最優先はコンテンツ追加ではなく、予算が本当に判断へ影響する仕組みである。
- 平均スコアだけで街や成功を判定してはいけない。
- 選択結果を、数値だけでなく人物と街の具体的変化として見せる必要がある。
- プレイヤーの役職、権限、政策の実施段階を明確にする必要がある。
- 12政策程度で因果と再プレイ性を検証してからデータを増やすべきである。

## 意見が衝突した点

| 論点 | 意見A | 意見B | 判断に必要な検証 |
|---|---|---|---|
| 選択前の情報 | 効果を見せると最適化されやすい | 子どもには比較材料が必要 | 正確な数値ではなく、方向・時期・受益者だけを見せて比較する |
| 不確実性 | 驚きと再プレイ性を作れる | 理由のないランダムは学習を妨げる | 予測範囲と、ずれた理由を結果で説明する試作を比較する |
| 政治の複雑さ | 交渉は判断を深くする | 読む量と操作が増える | 地域バス1政策だけを2段階化し、選択時間と理解度を測る |
| 失敗 | 緊張と立て直しを生む | 子どもが嫌になる可能性 | ゲームオーバーではなく、修正できる小さな失敗でテストする |

## 優先順位

1. 架空都市の市長など、プレイヤーの役割と権限を一文で固定する。
2. 地域バスの1ターンだけ、政策選択、財源、合意形成、実施結果の2〜3段階へ作り直す。
3. 全81経路の予算、最低ゴール、街状態、結末分布を自動検査する。
4. 各政策に受益者、負担者、即時反応、維持費、効果時期を持たせる。
5. 平均に加えて最低ゴール、格差、将来負担を評価へ使う。
6. 史実・仮想・ゲーム仮定と出典をデータ項目として追加する。
7. コントラストと読み上げ可能なメーターを修正する。

## 最小の次ステップ

既存4ターンを一度に作り直さず、地域バスだけを縦に深くする。

1. 市長として政策案を受け取る。
2. 利用者、納税者、職員の3者から条件を聞く。
3. 財源を「税」「運賃」「既存予算の組み替え」から選ぶ。
4. 試験運行後に、予測と実際の差を人物、街、数値で確認する。
5. 子どもを含む5人程度で、理解、迷い、納得、再挑戦意欲を検証する。
