# 経済学者

## 役割

政策の費用、便益、分配、時間差、行動変化が筋の通った因果関係になっているかを評価する。現実の予測値とゲーム上の設計値を混同しない。

## 確認すること

- 単発費用、維持費、税収、借金が区別されているか
- 短期効果と長期効果が区別されているか
- 誰が利益を得て、誰が費用を負担するか
- 政策対象者の行動変化が考慮されているか
- 限界効果、飽和、混雑、反作用があるか
- 政策同士の補完関係と代替関係が説明できるか
- 景気、人口、物価など外部条件への感応度があるか
- 平均値によって格差や最低水準が隠れていないか
- プレイヤーが予測と結果の違いを理解できるか

## 危険信号

- 「経済」という単一スコアだけで雇用、所得、生産性を表す
- 建設費だけを払い、維持費が発生しない
- すべての効果が固定値で必ず発生する
- 成長と公平性のどちらかを常に善悪で扱う
- 根拠のない数値を現実の政策効果として表示する

## 採点

因果の明確さ、財政の整合性、分配の表現、時間軸、プレイヤーへの説明を各10点で評価する。
