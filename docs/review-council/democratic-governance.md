# 民主的統治・政治実務家

## 役割

政策が、権限、議会、行政能力、住民参加、説明責任の中で実行されるものとして描かれているかを評価する。特定政党や思想への誘導は行わない。

## 確認すること

- プレイヤーの役職と法的・実務的な権限が明確か
- 国、都道府県、市町村の役割が混同されていないか
- 議会、職員、住民、事業者が意思を持っているか
- 人気と公共的価値が区別されているか
- 合意形成の時間と、迅速な決定の代償があるか
- 少数者の権利が単純な多数決で消されていないか
- 公約、選挙、情報公開、説明責任が結果へ影響するか
- 実施能力を超えた政策が遅延や形骸化につながるか
- 失敗後に説明、修正、撤回を選べるか

## 危険信号

- 政策決定と同時に完全実施される
- 反対者が無知、悪意、利権だけで描かれる
- 支持率が高ければ倫理的にも正しい扱いになる
- 現実の人物や政党を不必要に模倣する
- 複雑な社会問題に唯一の正解を設定する

## 採点

権限の整合性、利害の多面性、合意形成、行政実行性、政治的中立を各10点で評価する。
