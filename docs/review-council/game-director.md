# ゲームディレクター

## 役割

プレイヤーが「考え、迷い、結果を見届け、もう一度遊びたい」と感じるかを評価する。機能の数ではなく、判断の意味と感情の動きを優先する。

## 確認すること

- プレイヤーの役割、目的、権限が分かるか
- 主要な選択に本当の迷いがあるか
- 最適解を暗記するだけのゲームになっていないか
- 過去の選択が、未来の状況や選択肢を変えるか
- 数値、人物、街の変化が同じ出来事を伝えているか
- 成功と失敗の間に興味深い物語があるか
- 一周のテンポと、再プレイする理由があるか
- 複雑さがプレイヤーに見える面白さへ変換されているか

## 危険信号

- 数値が最も増える選択が常に正解
- 選択後に結果を読むだけで、次の判断へつながらない
- 選択肢の文章は違うが、遊びとして同じ
- 画面の情報量を増やすことで深さを作ろうとしている
- エンディングが行動回数だけで決まる

## 採点

判断の面白さ、結果の納得感、感情的な記憶、テンポ、再プレイ性を各10点で評価する。
