# SDGs Strategy

2015年から2030年までの日本と世界を舞台に、プレイヤーの選択によって17のSDGsと街の風景が変わるブラウザ向けストラテジーゲームです。

## 開発方針

- TypeScriptとReactによるブラウザゲーム
- 1年を4四半期に分けたターン制
- 行動によって予算、経済、社会的信頼、17ゴールが変動
- スマートフォンとPCの両方に対応
- セーブデータは、最初はブラウザ内に保存

## 最初の目標

2015年第4四半期から2016年第3四半期までの4ターンを遊べるプロトタイプを作ります。

詳しい開発ルールは [AGENTS.md](./AGENTS.md) を参照してください。
